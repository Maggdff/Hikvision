# صانع SVGA لـ VoiceUp

يحوّل فيديو/GIF أو مجلد صور PNG إلى ملف `.svga` يعمل مع مشغّل VoiceUp، ويكتب صورة معاينة بجانبه.
لا يتطلب أي تعديل على التطبيق: ارفع الناتج إلى `voiceup-assets` وأضفه من شاشة الإدارة.

## الطريقة 1: من GitHub فقط (بلا جهاز كمبيوتر)
ضع هذا المجلد في المستودع `voiceup-assets`:
- `make_svga.py` في الجذر.
- `.github/workflows/make-svga.yml` (أنشئه من Add file ← Create new file واكتب المسار كاملاً ثم الصق المحتوى).

ثم لكل ملف جديد:
1. ارفع الفيديو إلى `inbox/` (مثل `inbox/crown.mp4`).
2. Actions ← **Make SVGA** ← Run workflow، واملأ: المسار، والناتج (مثل `gifts/crown.svga`)، والنوع، والمفتاح.
3. بعد دقيقة يُضاف الملف والمعاينة (`.preview.png`) إلى المستودع تلقائياً. افتح المعاينة وتأكد أن الشفافية سليمة.

## الطريقة 2: على جهاز كمبيوتر
```
pip install pillow numpy      # ومعه ffmpeg
python make_svga.py clip.mp4 out/vip7.svga --kind frame --key green --hole 0.58
python make_svga.py clip.mp4 out/crown.svga --kind gift  --key black
```

## الخيارات
| الخيار | المعنى |
|---|---|
| `--kind frame` | إطار صورة شخصية: لوحة 400×400، والصورة المخزنة 256×256 |
| `--kind gift` | تأثير هدية بورتريه: لوحة 640×1138، والصورة المخزنة 320×569 |
| `--key green` / `#RRGGBB` | خلفية لون مسطح تُحذف (للأجسام الصلبة والمعدنية) |
| `--key black` | خلفية سوداء تتحول شفافية حسب السطوع (للتوهج والنار والألعاب النارية والجسيمات) |
| `--key none` | لا مفتاح: لصور PNG التي فيها شفافية أصلاً |
| `--hole 0.58` | للإطارات: يفرّغ دائرة مركزية قطرها 58% ليظهر وجه المستخدم |
| `--max-frames 130` | أقصى عدد إطارات (الافتراضي 130 عند 15 إطاراً/ثانية ≈ 8.7 ثانية) |
| `--colors 256` | قلّله (مثل 128) لتصغير الحجم |

## نصائح للجودة
- خلفية **خضراء مسطحة** للأجسام الصلبة؛ **سوداء** للضوء فقط. الجسم الداكن على خلفية سوداء يختفي جزء منه.
- كاميرا ثابتة، بلا ظلال على الخلفية، ولا نص ولا علامة مائية.
- الإطار: الحلقة ثابتة في المنتصف والفتحة بنفس لون الخلفية، والحركة في اللمعان والجواهر والجسيمات.
- إذا ظهرت حواف خضراء: ارفع `--tol` قليلاً (مثل 0.35). إذا اختفت أجزاء من الجسم: اخفضه (مثل 0.22).
- الحد الموصى به 10MB للملف.
