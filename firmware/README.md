# برنامج صندوق الحنفية (ESP32 + NFC + قفل)

> **الحالة**: مكتوب وفق بروتوكول الجسر (`src/SmartWater.Gate`) ومتجه التوقيع المشترك، لكنه **لم يُترجَم ولم يُجرَّب على عتاد**.
> اختبار التوافق الوحيد المتاح الآن: متجه التوقيع (اختبار C# + `tools/sign_check.py` + الأمر `SELFTEST` على الجهاز).

## البناء والرفع (PlatformIO)
```
cd firmware
pio run                 # بناء
pio run -t upload       # رفع
pio device monitor      # الطرفية التسلسلية 115200
```
المنصّة `pioarduino` (core 3.x) مطلوبة لـ`ETH.h` مع W5500. للـWi-Fi بدل Ethernet: `-DUSE_ETH_W5500=0` في `platformio.ini`.
واجهة `ETH.begin(...)` لـW5500 تختلف بين إصدارات core؛ إن لم تُترجَم فعدّل الاستدعاء في `netBegin()` حسب إصدارك.

## إعداد الجهاز (مرة واحدة عبر الكبل التسلسلي)
1. في برنامج ويندوز: تبويب «الصناديق» ← أضف المحطة والصندوق ← «تسجيل الجهاز / مفتاح جديد» (يظهر المفتاح مرة واحدة).
2. من الطرفية:
```
SET deviceid ESP1
SET key <64 خانة hex>
SET host 192.168.10.10
SET port 8080
SET wifi <ssid> <password>      (Wi-Fi فقط)
SELFTEST                         ← يجب أن يطبع SELFTEST OK
STATUS
REBOOT
```
المفتاح يُحفظ في NVS ولا يُطبع أبدًا. للإنتاج فعّل **تشفير الفلاش** و**الإقلاع الآمن** في ESP-IDF/Arduino.
إن مُسح NVS من الجهاز فسجّل الجهاز من جديد في لوحة التحكم (يصفّر عدّاد التسلسل في الخادم).

## الأطراف (ESP32-DevKitC الكلاسيكي — راجعها على لوحتك، `src/config.h`)
| الوظيفة | GPIO |
|---|---|
| بوابة MOSFET القفل (عبر 220Ω + سحب 10k للأسفل) | 25 |
| LED أخضر / أحمر / صافرة | 26 / 27 / 32 |
| PN532 I²C SDA / SCL | 21 / 22 |
| PN532 IRQ / RSTO | 17 / 14 |
| W5500: SCK / MISO / MOSI / CS / RST | 18 / 19 / 23 / 5 / 16 (INT غير موصول = استطلاع) |

> تعديل على وثيقة التصميم: أُضيف طرفا IRQ وRST للقارئ PN532 لأن مكتبة Adafruit تستعملهما.
أخرج PN532 إلى وضع I²C (مفاتيح DIP على اللوحة) قبل التجربة.

## سلوك الجهاز
- **القرار دائمًا من الجسر**: لا يسمح الجهاز محليًا بأي بطاقة؛ عند انقطاع الشبكة يرفض مع إشارة «لا اتصال» (3 وميضات حمراء قصيرة) ويسجّل حدثًا.
- **القفل الآمن**: يُضبط على «مقفل» أول ما يُقلع. الفتح يتبع حالة الجسر المطلوبة بإيجار يتجدد مع كل نبضة (5 ث)؛ إن توقف الجسر أو لم يُعرف الوقت يعود الجهاز للحالة الآمنة. وسقف محلي 20 دقيقة مستقل عن الجسر.
- **لا أوامر قديمة**: يتجاهل الأمر المنتهي أو ذا الإصدار الأقدم، ويطبّق الحالة المطلوبة الأحدث فقط.
- **الوقت**: لا RTC ولا NTP؛ يأخذ وقت الخادم من الردود (أول طلب يردّ `StaleTime` ومعه الوقت فيُعاد).
- **الأحداث بلا اتصال**: تُخزَّن في LittleFS (حتى ~16KB) وتُرفع لاحقًا بتسلسل فريد.
- **القارئ**: إن عطل يعيد التهيئة كل 30 ث ويبلّغ `readerOk=false`.
- **إشارات**: أخضر + صافرة = سمح؛ أحمر مزدوج = رفض؛ أحمر ثلاثي قصير = لا اتصال؛ أخضر مزدوج = التُقطت بطاقة للتسجيل.

## اختبارات على الطاولة (بلا قفل ولا ماء)
1. `SELFTEST` ← OK.  2. `STATUS` ← net=up، online=1، timeSynced=1 بعد أول نبضة.
3. مرّر بطاقة غير مسجّلة ← أحمر مزدوج، وحدث `deny.unknown_card` في لوحة التحكم.
4. سجّل البطاقة بوضع التعلّم ← أخضر مزدوج ثم تُقبل لاحقًا.
5. افصل الكبل ومرّر بطاقة ← أحمر ثلاثي؛ أعد الكبل ← تظهر أحداث `dev.tap_offline` في السجل.
6. أوقف الجسر وراقب: يعود المخرج للحالة الآمنة خلال ≤ 120 ثانية (الإيجار).
7. فاز؟ **قِس بملتيميتر** مخرج القفل قبل توصيل أي قفل حقيقي.
**كل هذه البنود «لم تُنفَّذ» حتى تجرّبها على العتاد.**
