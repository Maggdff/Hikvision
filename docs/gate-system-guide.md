# دليل نظام صناديق الحنفيات (التركيب، التشغيل، الصيانة، الاختبارات)

> **تنبيه سلامة**: هذا الدليل ليس بديلًا عن فني كهرباء مؤهَّل. تأكد من تصنيف القفل (جهد/تيار/تشغيل متواصل) من ورقة بياناته، وافحص التوصيل بملتيميتر **قبل** توصيل القفل. لم يُركَّب أي شيء من هذا على عتاد حتى الآن.

## 1. القائمة المقترحة للمواد لكل صندوق (تُراجَع بحسب القفل المختار)
| البند | المواصفة |
|---|---|
| لوحة تحكم | ESP32-DevKitC (الكلاسيكي) |
| شبكة | وحدة W5500 (SPI) وكبل Ethernet (أو Wi-Fi كبديل) |
| قارئ بطاقات | PN532 (I²C) — ليس RC522 إن أردت DESFire لاحقًا |
| مصدر طاقة | 12V DC بتيار ≥ ضعف تيار القفل (مثلًا 3–5A) |
| محوّل خافض | 12V→5V بتيار ≥ 2A (للـESP32 والقارئ) |
| تشغيل القفل | MOSFET منطقي المستوى (مثل IRLZ44N) **أو** وحدة ريليه معزولة ضوئيًا |
| حماية | فيوز على 12V، ديود شوتكي عكسي على القفل (مثل SS34)، TVS على الدخل (مثل SMBJ15A)، حماية قطبية عكسية |
| قفل | **A (موصى به)**: مزلاج كهربائي (Electric strike) بتصنيف تشغيل متواصل مع باب ذاتي التعشيق. **B**: قفل مغناطيسي |
| ملحقات | LED أخضر/أحمر وصافرة (اختياري)، علبة مقاومة للماء والغبار IP65+، مفتاح ميكانيكي احتياطي للباب |
ضع البند `LOCK_TYPE_STRIKE` في `firmware/src/config.h` حسب نوع القفل (1 للمزلاج، 0 للمغناطيسي).

## 2. مخطط التوصيل (مبدئي)
```
 220V AC -> [PSU 12V DC] -+--[Fuse 3A]--+---------------------+
                          |             |                     |
                          |        LOCK + (red)         [Buck 12V->5V 2A]
                          |             |                     |
                          |        LOCK - ----+               +-> ESP32 VIN (5V)
                          |                   |               |
                          |    Schottky diode across the lock  +-> PN532 VCC (3.3V من ESP32)
                          |    (cathode to +12V) + TVS on input
                          |                   |
                          |              Drain (logic-level N-MOSFET)
                          |   GPIO25 -[220R]-> Gate ,  Gate -[10k]-> GND
                          |              Source
 PSU(-) -------------------+------------------+----------- ESP32 GND --- PN532 GND
```
- GPIO لا يقود القفل مباشرة. سلك تيار القفل سميك ومنفصل عن أرضي القارئ ويلتقيان عند مصدر الطاقة.
- مقاومة السحب 10k تضمن أن القفل في **الحالة الآمنة** أثناء إقلاع الـESP32.
- مواضع الأطراف في `firmware/README.md` وتُراجَع على اللوحة الفعلية (تجنّب أطراف الإقلاع 0 و2 و12 و15).

## 3. التركيب والتشغيل خطوة بخطوة
1. اختبر الصندوق على الطاولة **بلا قفل** (بنود `firmware/README.md`)، وقِس مخرج القفل بملتيميتر.
2. ركّب الدائرة في علبة محكمة، وثبّت القفل بحيث **لا يتلف إن أُغلق والباب مفتوح** (لا مزلاج محرّك بلا حساس).
3. في برنامج ويندوز → تبويب «الصناديق» → «إعدادات الجسر»: فعّل، وحدّد عنوان شبكة الكمبيوتر والمنفذ وسياسة الرصيد (يُنصح بـP2 بسقوف خاصة لكل عميل، انظر 4).
4. افتح المنفذ في جدار ويندوز لشبكة الصناديق فقط (الأمر في `README.md`).
5. «الصناديق والمحطات»: أضف المحطة (رقم، اسم، تسلسل/تفرّع)، ثم الصندوق (رقم، المحطة، الحنفية، **العدّاد 1 أو 2**، معرّف الجهاز).
6. «تسجيل الجهاز / مفتاح جديد» ← انسخ المفتاح ← احقنه بالكبل التسلسلي (`SET key ...`) مع `deviceid` و`host` و`port`. ثم `SELFTEST` ← يجب `OK`.
7. تأكد من ظهور الصندوق «متصل» في الجدول.
8. **البطاقات**: اختر الصندوق ← «تعلّم بطاقة» ← مرّر البطاقة ← اختر الوايت ← «تسجيل البطاقة الملتقطة». (البطاقة الملتقطة لا تفتح شيئًا أثناء التعلّم.)
9. **سقوف العملاء**: لكل عميل سقفه الخاص (أقصى دين مسموح بعد التعبئة)، والافتراضي لمن لا سقف خاصًّا له.
10. جرّب بطاقة حقيقية على صندوق واحد **بلا ماء** وراقب الجدول والسجل قبل التشغيل الفعلي.

## 4. قواعد العمل التي ينفذها الجسر
- **المطلوب** = الكمية المعتمدة للوايت (كما أدخلتها) × سعر البرميل. لا خصم إضافي ولا حدّ إيقاف.
- **P1** (مدفوع مسبقًا): (الدائن − المعلّق) ≥ المطلوب. **P2**: (الصافي − المعلّق − المطلوب) ≥ −سقف العميل. **P3**: تسجيل فقط.
- **المعلّق** = زفات/فواتير لم تُرسل إلى EBS بعد (لأن EBS لا يراها). فأرسل الفواتير بانتظام لئلا يتراكم.
- وايت واحد في المحطة، وعميل واحد في عملية واحدة. بطاقة الوايت نفسه على الصندوق الثاني تنضم لنفس العملية بلا فحص رصيد ثانٍ.
- **القفل** لا يُرسل إلا عند: انتهاء التعبئة ومهلة الدقيقة، كل العدّادات المشاركة ساكنة، وقراءاتها سليمة حديثة، والكاميرا والمحرك شغّالان. غير ذلك يبقى مفتوحًا ويُسجَّل تنبيه.
- لا حساس للباب: لا يعرف النظام هل أُغلق الباب فعلًا. والمزلاج ذاتي التعشيق يحميه ميكانيكيًا.
- **الفتح الطارئ**: مفتاح ميكانيكي في القفل، أو «فتح يدوي» من نافذة ويندوز (بسبب مكتوب وتدقيق).

## 5. الصيانة والأعطال
| العَرَض | الفحص |
|---|---|
| صندوق «غير متصل» | كبل الشبكة/الطاقة، `STATUS` على الجهاز، جدار الحماية، الأحداث `auth.*` في السجل |
| «رفض: النظام غير جاهز» | الكاميرا أو المحرك متوقف؛ تبويب المراقبة |
| «رفض: الرصيد غير كافٍ / تعذّر التحقق» | رصيد العميل وسقفه؛ «تحميل العملاء» في تبويب EBS؛ اتصال EBS |
| أمر قفل غير مؤكد (`fault.lock_unconfirmed`) | الجهاز؛ استعمل «قفل يدوي» ثم افحص الشبكة |
| `fault.unauthorized_flow` | ماء يتدفق من حنفية بلا تصريح (فتح بالقوة/بلا بطاقة)؛ لا يمكن إيقافه من النظام |
| صندوق مفتوح والحالة المطلوبة مقفلة (`fault.stuck_unlocked`) | القفل الميكانيكي/الدائرة؛ «قفل يدوي» |
- راجع سجل الأعطال يوميًا. السجلات النصية في `%LocalAppData%\SmartWaterMonitor\logs`.
- لا تُبدِّل المفتاح الخام للجهاز في الوثائق أو المحادثات. استبدال مفتاح يتم بإعادة «تسجيل الجهاز».

## 6. النسخ الاحتياطي والاستعادة
- **النسخ**: أغلق البرنامج (خروج من قائمة الأيقونة) ثم انسخ المجلد `%LocalAppData%\SmartWaterMonitor` كاملًا (swings.db، trucks.db، ebs.db، gate.db، config.json، الصور).
- **الاستعادة على نفس الجهاز**: أعد المجلد والبرنامج مغلق.
- **تنبيه مهم**: مفاتيح الأجهزة وسرّ البطاقات وبيانات EBS مشفّرة بـDPAPI على مستوى الجهاز. **لا تُفكّ على كمبيوتر آخر**؛ عند الاستعادة على جهاز جديد أعد تسجيل الأجهزة (مفاتيح جديدة) والبطاقات وأدخل بيانات EBS من جديد. (إن احتجت نسخة تُستعاد على جهاز آخر فأضيف تصديرًا بكلمة مرور.)

## 7. الاعتماديات
- برنامج ويندوز: .NET 8 (WPF + ASP.NET Core المشترك)، OpenCvSharp4 + runtime.win، Microsoft.Data.Sqlite، System.Security.Cryptography.ProtectedData، xUnit (اختبارات).
- البرنامج المضمَّن: ArduinoJson 7، Adafruit PN532، Adafruit BusIO، منصّة pioarduino (core 3.x).
