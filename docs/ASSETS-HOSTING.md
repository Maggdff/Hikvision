# استضافة أصول الهدايا والإطارات (بلا بطاقة بنكية)

لا تبقى الأيقونات وملفات SVGA داخل APK. تُرفع إلى أي استضافة ملفات ثابتة، ويُدير المشرف الأسماء والأسعار والمسارات من التطبيق
(شاشة «أنا» ← «إدارة الهدايا والإطارات»، لمن معرّفه في `ADMIN_UIDS`).

## كيف يعمل (مستقل عن المزوّد)
- الخادم يحفظ **مسار** كل ملف (مثل `gifts/bugatti.svga`) ويبني الرابط: `ASSETS_BASE_URL` + `/` + المسار + `?v=<وقت آخر تعديل>`.
- التطبيق ينزّل الملف مرة ويخزّنه على الجهاز؛ تعديل المشرف يغيّر `?v=` فيتجدد الملف تلقائياً.
- مجلد `remote-assets/` فيه الملفات الجاهزة بمساراتها: `gifts/bugatti.webp`، `gifts/bugatti.svga`، `frames/vip6.svga`.

## الخيار 1 (موصى به): GitHub Pages (مجاني، بلا بطاقة، لا يتوقف)
1. على GitHub أنشئ مستودعاً **عاماً** باسم `voiceup-assets`.
2. Add file ← Upload files: اسحب مجلدي `gifts` و`frames` من `remote-assets/` (تبقى المسارات كما هي) ← Commit.
3. Settings ← Pages ← Source: `Deploy from a branch` ← `main` / `(root)` ← Save. انتظر دقيقة.
4. الرابط: `https://<اسم-حسابك>.github.io/voiceup-assets`. على Railway اضبط:
   `ASSETS_BASE_URL=https://<اسم-حسابك>.github.io/voiceup-assets` (بلا `/` أخيرة) وأعد النشر.
5. ملف جديد = ارفعه إلى المستودع بالمسار الذي ستكتبه في شاشة الإدارة. الكاش على Pages نحو 10 دقائق لكل رابط، و`?v=` يجبر التحديث عند تعديل الإدخال.
- القيود: حد حجم المستودع الموصى به نحو 1GB، ونطاق نقل شهري مرن (soft). شروط GitHub Pages تمنع استخدامه كمنصة تجارية؛ مناسب للتجربة والإطلاق الصغير، وانقل لاحقاً إن كبر المشروع.

## الخيار 2: Supabase Storage (رفع بالسحب من اللوحة، بلا بطاقة)
1. أنشئ مشروعاً مجانياً ← Storage ← New bucket باسم `voiceup-assets` وفعّل **Public bucket**.
2. ارفع الملفات بمساراتها (`gifts/...`، `frames/...`).
3. `ASSETS_BASE_URL=https://<project-ref>.supabase.co/storage/v1/object/public/voiceup-assets`
- القيود (بحسب ما أعرفه، تحقق منها): المشاريع المجانية تُوقَف بعد فترة بلا نشاط، وحصة التخزين والنقل صغيرة. إيقاف المشروع يعني اختفاء الأصول.

## ما لا أنصح به
- مجلد من الخادم نفسه على Railway: يستهلك رصيد النقل لديك.
- raw.githubusercontent.com: غير مخصص للاستضافة وقد يُحدّ معدّله.

## إضافة هدية/إطار جديد
ارفع الملف بمساره، ثم في شاشة الإدارة اضغط `+` واكتب المعرّف والاسمين والسعر ومسار الملف.
السعر الجديد يسري على الإرسال/الشراء القادم فقط.
